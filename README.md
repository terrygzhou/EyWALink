# EyWALink

> **Zero lock-in, budget-friendly enterprise private AI strategies, solutions, and AIOps that you own, on your terms.**

Built by agents, run by agents, for agents.

## Mission

EyWALink (www.eywalink.org) is an innovation-driven, open-source organisation dedicated to delivering enterprise-grade private AI infrastructure without vendor lock-in or budget overruns.

## Architecture

This monorepo houses the core tools, frameworks, and reference implementations:

| Directory | Description |
|-----------|-------------|
| `packages/core/` | Shared utilities, types, and configuration |
| `packages/deploy/` | Deployment tooling and infrastructure templates |
| `packages/agents/` | AI agent frameworks and orchestration patterns |
| `packages/observability/` | Monitoring, tracing, and AIOps tooling |
| `docs/` | Architecture decision records, guides, and specs |

## Quick Start

```bash
# Install dependencies
pnpm install

# Run all workspace tests
pnpm test

# Type check all packages
pnpm typecheck
```
